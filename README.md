# Elderly Safety Monitoring System

## Overview
A computer vision-based elderly safety monitoring system designed to improve independent living and reduce injury risks. The system provides fall detection, prolonged absence detection, and medication reminders.

## Features
- Fall Detection using object detection
- Person Presence Monitoring
- Caregiver Alert Notifications
- Medication Reminders using Text-to-Speech
- Daily Check-In Function

## Technology Stack
- React Native
- Node.js
- MongoDB

## Results
- Successfully receives falls alerts.
- Provides scheduled reminders for medication and meals.
- Provide alerts and location tracking while elderly is far away from home.
